# 邮箱工作台正式升级

目标：将认可的本地原型接入现有 Go/Vue/PostgreSQL 系统，在 OVH 原安装上保留已有数据升级。

## 必须完成的验收

- 真实收件箱：分页/筛选/搜索、纯文本与安全 HTML、附件/原文下载、独立网页已读/星标/归档/垃圾箱及恢复。
- 主号、地址、分组、凭据、Apple 管理连接、邮箱池、自动计划、批量创建/删除和日志在新导航可达；沿用认证与 CSRF。
- 历史补取：持久任务、独立时间范围和 UID 游标、分批提交、暂停/恢复/取消、断点续作，不能回退实时游标，不能重放未知 Apple 创建副作用。
- 后台常驻：无需浏览器/OTP 请求即可读取新信；每主号可开关，共用连接预算，断连退避、配置变化撤销旧观察，重启恢复。
- 长任务：关闭页面后继续，任务状态与结果持久化，重新打开恢复，限流/失败可解释；进度不会伪造。
- 兼容：已有主号/地址/原凭据、分组、Pool 使用历史和邮件原文保留；现有公开 API 契约验证。
- 部署：隔离副本迁移与验收，完整备份恢复核对，固定镜像/源码版本，单应用实例切换，可回退；上线真实浏览器与收件验证。

## 约束

不使用模拟数据驱动正式界面；演示入口保持独立。新增数据库状态采用加法迁移。历史缺失或已淘汰内容明确展示，不承诺上游已删除历史可恢复。重任务按 AGENTS.md 串行和资源门槛运行。实际部署细节与敏感材料不进入本文件。

## 当前进度

- 已有独立原型和浏览器体验验证。
- 已接入真实邮件 API、独立网页状态、新收件箱、历史补取和后台常驻。
- Go 全套回归、265 项前端测试、正式前端构建及隔离 PostgreSQL 迁移验证通过；已用原安装的数据副本验证登录、真实正文、原文下载、状态恢复及持久任务。
- 历史任务使用真实 IMAP 测试服务验证分批、时间范围、游标和重启恢复；实际 Apple 收件与创建仍须上线后独立验收。
- 工作台代码已部署并完成真实历史补取、关闭页面后的地址创建、原始邮件校验及备份恢复核对；部署回执与敏感恢复材料由目标环境单独保管。
- 自动计划继续沿用原有启停状态。批量任务支持持久化创建间隔，慢速任务共用主号预算与冷却；关闭页面不停止，进程重启后从安全的等待检查点继续。正在创建而结果不确定的任务保持中断，避免重复创建。

## 项目分配的兼容与安全

新建项目使用安全分配策略：公开取件/IMAPS 只提供当前分配窗口内的邮件；超时且未确认使用的地址先暂停分配，由管理员核实；停用或轮换项目 Key 会同步撤销其当前地址的旧凭据。管理员工作台仍可查看全部保留归档。已有项目维持原策略，避免静默改变既有 API 合同；低层 Store.CreatePoolClient 保留兼容，管理界面新建通过 CreateSafePoolClient。
