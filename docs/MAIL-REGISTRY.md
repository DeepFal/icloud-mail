# 邮箱备注与服务登记

在本系统中记录邮箱用途、使用过的服务和账号标识。登记不会在第三方服务注册、登录或注销账号，也不存储第三方账号密码。邮件到达或出现验证码，不会自动把邮箱标记成已注册。

## 日常使用

- 收件箱的每封邮件显示所属隐私邮箱地址；打开邮件后，可以通过“编辑备注与服务登记”维护该邮箱。隐私地址列表的更多菜单也提供同一入口。
- 主号、隐私地址和分组筛选支持输入关键词。邮箱选择器按完整地址展示，可按地址或本地备注进行不区分大小写的子串搜索；有备注时显示第二行，没有备注时使用紧凑的单行。
- “服务登记”页面先选择服务，再按状态、邮箱地址、备注、登记账号标识、主号或分组查询。右上角也可直接查找任意邮箱资料。
- 新建服务填写名称，可选域名与说明。归档保留全部历史，阻止新增登记；已有登记仍可维护，恢复服务后可以继续新增。
- 一个邮箱可登记多个服务，同一个服务也可记录多个账号。账号标识用于区分这些记录，不填写密码或验证码。编辑时账号标识固定；更正标识可新增正确记录、核实后移除原记录。
- 批量登记只对本页明确勾选的邮箱生效。保存前会显示服务、数量和状态供确认。整批有一个无效邮箱或状态冲突时全部回退，不产生部分保存。

## 状态语义

| 状态 | 含义 |
| --- | --- |
| 未记录 | 对这个服务尚无任何本地登记；并不代表未注册 |
| 已注册 | 人工确认已完成注册 |
| 待确认 | 已有尝试或线索，注册结果尚未确认 |
| 确认未注册 | 人工核实未使用这个服务 |
| 已停用 | 曾有账号，目前已停用；不应视为从未注册 |

同一邮箱同一服务有多个账号时，列表按“已注册 > 待确认 > 已停用 > 确认未注册”汇总，详情保留每条记录。其他服务的登记不会影响所选服务的状态。已有任何使用记录时不能直接批量改成“确认未注册”，需要先核实并移除冲突记录。新增使用记录会撤去之前的“确认未注册”标记。

## 数据保留与兼容

本地备注独立于原有 `label`，不会修改或覆盖 Apple 目录标签。备注与服务登记以规范化的完整邮箱地址为身份保存，去除首尾空白并忽略大小写，不去点号、不剥离 `+tag`。删除再导入同一地址会恢复原有备注和登记。服务登记和邮箱池的使用、领取、退役规则互相独立，不因为登记服务而改变库存。

迁移新增 `mailbox_notes`、`mail_services` 和 `mailbox_service_registrations`，不删除旧列、不变更已有凭据。SQLite 与 PostgreSQL 都通过启动迁移收敛；延续现有扩展表模式，不提升 v8 主版本。升级应按 DELIVERY.md 备份数据库、密钥与归档；本次功能包含后端和数据表，不能只替换前端资源。

## 管理 API

全部入口位于实际管理路径的 `/api/v1` 下，要求管理员 Session；所有写入还要求现有 `X-CSRF-Token`。邮箱资料与列表均不返回邮箱取件凭据。以下示例使用 `/admin/api/v1`：

- `GET /services?query=&include_archived=1`：返回 `{data:{items:[...]}}`。
- `POST /services`：`{name,domain,note}`，创建服务。
- `PATCH /services/:id`：可更新 `name`、`domain`、`note`、`archived`，省略字段保留原值。
- `GET /aliases/:id/profile`：邮箱地址、备注、更新时间与全部服务登记。
- `PATCH /aliases/:id/profile`：`{note:"..."}`。必须显式传入，空字符串清除备注。
- `PUT /aliases/:id/registrations`：`{service_id,account_identifier,status,note}`。地址、服务、规范化账号标识相同时幂等更新。
- `DELETE /aliases/:id/registrations/:registrationID`：移除本地登记，不影响服务实际账号；该登记必须属于当前邮箱。
- `POST /service-registrations/batch`：`{alias_ids:[...],service_id,account_identifier,status,note}`，1–100 个不重复的邮箱；成功返回 `{data:{updated:N}}`。
- `GET /service-mailboxes?service_id=...&status=...&query=...&account_id=...&group_id=...&enabled_only=1&limit=50&offset=0`：服务必选；分页返回 `{data:{items,total,has_more}}`。`unrecorded` 只可用于查询，不能保存为登记状态。

服务名最多100字符，唯一比较使用 NFKC 与大小写归一化；域名只接受主机名，不接受 URL、路径或端口。邮箱备注与登记说明最多2000字符，账号标识最多200字符。搜索是字面量子串匹配，`%`、`_` 不作为通配符。列表最大单页200项。
