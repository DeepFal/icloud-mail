# 控制台设计约定

## 方向

以原生邮件工具为参考：固定导航、连续的列表与阅读分栏、紧凑工具栏、明确的选中态。真实邮箱与运行状态是内容中心，不增加装饰性仪表盘或伪造统计。

外观：浅色、深色、跟随系统，后台与登录页右上角切换，本地持久化并同步浏览器标签页。颜色集中于 `web/src/styles/theme.css`；组件使用语义 token。浅色以白色阅读面和暖灰导航区分层，深色使用中性炭灰；蓝色用于链接、焦点和需要强调的操作。选中项使用中性色 `--selection-bg`，普通工具按钮不做成主操作。移除背景色场、装饰玻璃和控件内阴影，仅弹窗、菜单等实际浮层使用投影。交互使用短时颜色反馈，不使用装饰缩放、持续动画、Canvas 或鼠标跟随滤镜。

字体优先系统 UI 字体；JS、CSS、图标均随应用本地打包，不调用外部 CDN。主题初始化使用同源 `assets/theme-init-v1.js`，在主包执行前应用偏好，兼容现有 CSP。该文件长期缓存，修改时须递增文件名版本。间距以 4 / 8 / 12 / 16 / 24 为主。

应用响应使用 `Cache-Control: no-store, no-transform`，避免 Cloudflare 自动注入外部统计脚本；静态资源仍长期缓存。依据 [Cloudflare 自动注入说明](https://developers.cloudflare.com/web-analytics/get-started/#sites-proxied-through-cloudflare)，发布验收须在真实浏览器中确认请求来源，源码扫描不足以发现代理层注入。

布局：左侧固定导航，右侧轻量顶栏和内容；标题左对齐，主操作靠右。收件箱分栏直接组成页面，不放入悬浮圆角卡片；发件人、主题和正文优先于图标、标签和辅助工具。主号的连接详情、自动创建计划明细折叠展示，状态、异常与常用操作常驻；批量创建与隐私地址同级。列表筛选和批量操作各有明确位置。表格保留虚拟滚动，移动端使用可操作的记录卡片。

```
导航          页面位置                         外观 / 当前管理员
              标题                            主操作 / 更多
              搜索 / 筛选
              选择数量 / 本页操作 / 批量操作
              表格
              分页
```

交互：跨页选择保留、筛选切换清选；勾选列拖动增选/取消，修饰键反选，边缘滚动。危险操作仍二次确认。完成任务不常驻。限流归为正常冷却；登录、网络、持久化异常仍清晰报告。尊重 reduced-motion 和 reduced-transparency；缺少 backdrop-filter 支持时使用不透明底色。所有颜色语义、焦点、禁用与 loading 状态须在两种外观下检查。

## 参考与取舍

- [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)：设计计划、信息层级、截图审查。
- [Reka UI](https://github.com/unovue/reka-ui)（MIT）：键盘和焦点管理的组件交互参考。
- [shadcn-vue](https://github.com/unovue/shadcn-vue)（MIT）：紧凑工具栏和组合式界面参考；默认分支为 `dev`，旧 `main` 文档不代表现状。
- [Element Plus](https://github.com/element-plus/element-plus)（MIT）：保留项目现有组件与虚拟表格，通过主题和布局统一设计，不额外引入第二套组件框架。

验收覆盖 1440 / 1024 / 390 / 320 宽度、键盘导航、弹窗焦点、跨页选择、拖选自动滚动、请求竞态、静态缓存与首屏资源。

## 收件箱交互与密度

当前正文独立于列表筛选结果保留：自动标记已读、取消星标或后台刷新不能让用户正在阅读的邮件跳走。主动切换文件夹、筛选或分页才重新选择邮件。归档与移到垃圾箱提供就地撤销，正文失败提供重新读取，搜索零结果提供清除筛选，首次收件提供添加主号入口。

桌面采用约 84px 的紧凑邮件行，日期与地址使用至少 12px 辅助文字。移动端常用操作命中区至少 44px，主号、地址和分组筛选按需展开；阅读工具栏将邮件操作与前后翻阅分为两行。工作台上下文不重复页面主标题，颜色统一由 `web/src/styles/theme.css` 提供。

区分刷新已归档列表和向主号提交收件请求。提交成功不代表上游收件已经完成；使用持续提示与真实主号状态连接两者。单个异常主号可直接进入详情，初次待验证、收取中、停用和读取失败分别说明，后台状态刷新遵循页面可见、在线和退避约定。

## 邮箱资料与服务登记

收件箱以完整邮箱地址标识收件归属，本地备注另行展示。邮箱、主号、分组与服务使用现有 Element Plus 可搜索选择器，输入关键词按字面量子串过滤；邮箱地址为主行，备注为辅助行，不以 Apple 标签替代地址。选项按真实内容占高度：桌面单行 34px、双行 52px，移动端单行至少 44px。使用实际布局与原生滚动处理混合行高，避免固定虚拟行高为单行内容预留双行空位。

邮箱资料通过同一抽屉维护备注和服务登记，保存分别进行，未保存输入在关闭前提示。服务登记页面采用目录与邮箱清单分栏，移动端改为目录在前、记录卡片在后。服务名称、域名、筛选、选择数量与批量操作各有固定位置；批量选择仅限本页，切换筛选或分页清空选择。状态由人工确认，明确区分“未记录”与“确认未注册”，不从邮件或验证码推断注册完成。
