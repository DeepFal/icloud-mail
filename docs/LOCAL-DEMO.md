# 本地交互原型

这是独立的 Vue 演示入口，全部使用浏览器内模拟数据，无需 Go、数据库或 Apple 登录。

```sh
npm --prefix web ci
npm --prefix web run demo
```

打开 `http://127.0.0.1:5174/demo.html`。服务只监听本机回环地址，端口占用时会报错，不自动切换端口。

可以体验：

- 收件箱：普通邮件正文、验证码、验证链接预览、示例 TXT 附件下载、搜索、分组、未读、星标和归档。
- 隐私地址：创建、编辑用途、暂停与恢复、按地址查看来信。
- 主号与连接：独立显示地址管理与收件状态，模拟添加主号、更新连接和收件验证。
- 项目与 API：个人地址入池、模拟领取、确认使用、未使用归还、超时进入待确认。
- 设置与诊断：外观、收件偏好展示、模拟活动和演示重置。

操作保存在当前浏览器的独立演示存储中；在「设置与诊断 → 重置演示」恢复初始样例。示例地址全部使用 `example.test`，无需输入真实密码。收件偏好仅用于展示，不启动后台任务。

`web/vite.demo.config.js` 不配置 API 代理。此入口不会调用真实管理接口、读取生产数据或连接 Apple；原有管理台入口保持独立。`npm --prefix web run build:demo` 将演示构建到 `web/dist/demo/`，重任务按项目 AGENTS.md 的排队和资源约定执行。
